# EDUVIA | إيدوفيا

موقع تعريفي متكامل لعلامة **إيدوفيا** التعليمية، عربي بالكامل مع اتجاه RTL، مبني بـ HTML وCSS وJavaScript فقط بدون أي حزم أو خطوة بناء.

> **ملاحظة مهمة:** هذه نسخة عرض أمامية (Front-end) جاهزة للنشر كموقع ثابت. النماذج ولوحة الإدارة تعمل محليًا في المتصفح، ولا يوجد خادم أو بريد فعلي أو دفع إلكتروني بعد. اقرأ قسم [الحدود الحالية](#الحدود-الحالية) قبل الإطلاق.

## التشغيل

لا يحتاج الموقع إلى تثبيت أو سيرفر. افتح `index.html` مباشرة في المتصفح.

لتجربة أقرب للواقع (وخاصةً عند نشر الموقع لاحقًا) يمكن تشغيل خادم ملفات ثابت بسيط، مثل:

```bash
# إن توفر Python
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## المزايا المنفذة

- تصميم عربي RTL كامل بهوية بصرية: كحلي عميق، بنفسجي هادئ، عاجي، ولمسات ذهبية وسماوية.
- خطوط عربية حديثة: `Tajawal` للعناوين و`IBM Plex Sans Arabic` للنصوص، مع `Outfit` للأرقام واللاتينية.
- كل الصفحات متجاوبة مع الجوال واللوحي وسطح المكتب، مع قائمة جوال ووصولية (skip link، ARIA، تركيز واضح).
- صور محلية محسّنة + فيديو محلي قصير مع صورة غلاف وتشغيل عند الطلب.
- تصفية الخدمات والأعمال، تبويبات المراحل، نافذة معاينة الأعمال، وإشعارات Toast.
- نموذج طلب كامل: تحقق من الاسم والجوال السعودي والبريد والتاريخ والموافقة، وتصفية الخدمات حسب المرحلة، ورقم مرجعي.
- روابط عميقة للخدمات: `request.html?service=presentation` تختار الخدمة والمرحلة تلقائيًا.
- لوحة إدارة محلية: إحصاءات، بحث وتصفية الطلبات، تغيير الحالة، حذف، تصدير CSV، عرض الرسائل، إضافة خدمات وأعمال، وإعدادات تواصل.
- SEO: عناوين وأوصاف لكل صفحة، Open Graph، Schema.org، sitemap، robots، وmanifest.
- احترام `prefers-reduced-motion`.

## لوحة الإدارة (نسخة تجريبية)

افتح `admin.html` من الفوتر أو مباشرة.

- **لا يوجد تسجيل دخول حقيقي.** اللوحة مخصصة للعرض المحلي فقط، ولا يجوز نشرها كواجهة إدارة إنتاجية.
- البيانات تُخزّن في `localStorage` داخل المتصفح نفسه، لذلك:
  - تظهر الطلبات والرسائل فقط على الجهاز/المتصفح الذي أرسلها.
  - لا تصل إلى أي خادم أو بريد.
  - تختفي عند مسح بيانات المتصفح.
- يمكن تصدير الطلبات بصيغة CSV من تبويب الطلبات.
- إعدادات التواصل في اللوحة تُفعّل روابط البريد/الهاتف/واتساب/الحسابات في الموقع بعد إعادة تحميل الصفحات، على نفس المتصفح فقط.

### مفاتيح التخزين المحلي

| المفتاح | المحتوى |
| --- | --- |
| `eduvia_requests_v1` | طلبات الخدمة |
| `eduvia_messages_v1` | رسائل التواصل |
| `eduvia_services_v1` | الخدمات المضافة من اللوحة |
| `eduvia_portfolio_v1` | الأعمال المضافة من اللوحة |
| `eduvia_settings_v1` | إعدادات التواصل |

## التخصيص

### تغيير الألوان والخطوط

كل المتغيرات في أعلى `assets/css/base.css` داخل `:root`:

```css
--navy-950: #070c17;
--violet-600: #6755cc;
--gold: #c7a365;
--ivory: #f7f3ea;
```

### تغيير بيانات التواصل

- **مؤقتًا:** من `admin.html` ← إعدادات التواصل (محلي فقط)، أو باستبدال النصوص داخل HTML:
  - `info@eduvia.example`
  - `+966 5X XXX XXXX`
- عند إدخال بيانات حقيقية عبر اللوحة، تصبح الروابط مفعّلة تلقائيًا (بريد/هاتف/واتساب).
- عند الإطلاق الفعلي: استبدل كل `https://eduvia.example` في:
  - وسوم `canonical` و`og:url`
  - `sitemap.xml`
  - `robots.txt`
  - بيانات `Schema.org` في `index.html`

### إضافة صور أو فيديو

ضع الملفات في `assets/img/` ثم استبدل المسار في الصفحة. الفيديو الحالي `assets/img/eduvia-showreel.mp4` مع غلاف `showreel-poster.jpg`؛ لتغيير الفيديو استبدل الملفين مع الحفاظ على الاسمين أو حدّث المسارين في `index.html`.

### إضافة خدمات أو أعمال دائمة

- من لوحة الإدارة: تظهر مباشرة في `services.html` و`portfolio.html` على نفس المتصفح.
- للإضافة الدائمة لكل الزوار: أضف بطاقة HTML جديدة داخل `#services-grid` أو `#works-grid` بنفس بنية البطاقات الموجودة، مع `data-category` المناسب.

## الحدود الحالية

هذه النسخة **ليست** نظامًا إنتاجيًا كاملًا بعد:

1. **لا يوجد خادم أو قاعدة بيانات.** الطلبات والرسائل محلية في المتصفح فقط.
2. **لا يوجد بريد فعلي** ولن تصل الطلبات إلى إيدوفيا تلقائيًا.
3. **لا يوجد دفع إلكتروني.** شروط الأسعار توضح ذلك.
4. **لا يوجد تسجيل دخول آمن** للوحة الإدارة.
5. بيانات التواصل والأسعار والنماذج **تجريبية/استعراضية**.
6. الفيديو والصور من مصادر مجانية (Unsplash / Mixkit) وتحتاج مراجعة الترخيص قبل الاستخدام التجاري الواسع.

### خطوات الإطلاق المقترحة

1. استبدال النطاق والبيانات التجريبية بالرسمية.
2. ربط النماذج بخادم/خدمة بريد مع حماية من Spam (مثل reCAPTCHA).
3. بناء لوحة إدارة حقيقية بمصادقة وقاعدة بيانات.
4. إضافة بوابة دفع سعودية عند الحاجة.
5. مراجعة الصور والفيديو والتراخيص، وإضافة صفحة الشروط النهائية.
6. اختبار الوصولية والأداء على أجهزة حقيقية.
